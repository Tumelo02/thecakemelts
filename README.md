# The Cake Melts - Website

A beautiful, responsive website for The Cake Melts bakery featuring custom cakes and cupcakes.

## Features

- 🎂 Responsive design (mobile-friendly)
- 📧 Contact form with email functionality
- 🖼️ Image gallery for cakes
- 👩‍🍳 Baker profile section
- 💬 Customer testimonials
- 📍 Location with Google Maps integration

## File Structure

```
Cake_Website/
├── index.html              # Main HTML file
├── css/                    # Stylesheets
│   └── templatemo-style.css
├── js/                     # JavaScript files
│   ├── custom.js
│   └── contact-form.js     # Contact form handler
├── images/                 # Template images
├── cake images/            # Your cake images
│   ├── 1.jpg - 6.jpg      # Cake gallery images
│   ├── Chef Image.jpg     # Baker photo
│   ├── Logo.png           # Company logo
│   ├── Website hero image4.jpg  # Hero background
│   └── ...
├── php/                    # PHP backend
│   └── contact.php         # Contact form handler
└── DEPLOYMENT_GUIDE.md     # Free hosting guide
```

## Quick Start

1. **Local Testing:**
   - Use XAMPP, WAMP, or MAMP for local PHP server
   - Place files in `htdocs` folder
   - Visit `http://localhost/Cake_Website`

2. **Deployment:**
   - See `DEPLOYMENT_GUIDE.md` for free hosting options
   - Recommended: InfinityFree (free PHP hosting)
